TP5 - Exercice 6 : L'Effet Parallaxe

Découvrez comment créer un effet de parallaxe avec JavaScript pour donner de la profondeur à vos pages web.

Effet Parallaxe

Qu'est-ce que l'effet parallaxe ?

L'effet parallaxe est une technique qui crée une illusion de profondeur en faisant défiler différentes couches de contenu à des vitesses différentes.

Lorsque vous scrollez, l'arrière-plan se déplace plus lentement que le premier plan, simulant ainsi la perception de profondeur que nous avons dans le monde réel.

Comment ça marche ?

Technique d'implémentation

L'effet parallaxe utilise JavaScript pour contrôler la vitesse de défilement de différents éléments :

  1. Structure HTML : Créez des conteneurs avec des couches (background, overlay, content)
  2. Attributs data : Ajoutez un attribut data-speed pour contrôler la vitesse
  3. JavaScript : Écoutez l'événement scroll et calculez le déplacement
  4. Transform CSS : Appliquez translateY() pour déplacer les éléments
// JavaScript pour l'effet parallaxe function initParallax() { const parallaxBgs = document.querySelectorAll('.parallax-bg'); window.addEventListener('scroll', () => { parallaxBgs.forEach(bg => { const speed = bg.dataset.speed || 0.5; const section = bg.closest('.parallax-section'); const rect = section.getBoundingClientRect(); // Appliquer l'effet uniquement si visible if (rect.top < window.innerHeight && rect.bottom> 0) { const offset = window.pageYOffset; const yPos = -(offset * speed); bg.style.transform = `translateY(${yPos}px)`; } }); }); } initParallax();

Applications

Cas d'usage de l'effet parallaxe

  • Sites portfolios - Pour créer une navigation immersive et moderne
  • Pages produits - Pour mettre en valeur des caractéristiques
  • Storytelling - Pour raconter une histoire captivante de manière visuelle
  • Landing pages - Pour guider l'attention de l'utilisateur

Connaissances

JavaScript pour animations de scroll, manipulation du DOM, calcul de positions (getBoundingClientRect(), pageYOffset), transformations CSS (translateY), optimisation des performances.

Difficulté

Intérêt

Technique essentielle pour créer des sites immersifs et modernes. Comprendre les calculs de scroll et l'optimisation des performances pour des animations fluides.
