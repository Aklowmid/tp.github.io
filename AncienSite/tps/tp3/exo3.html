Technique & Difficulté

J'ai utilisé une Media Query à 980px pour basculer l'affichage. La difficulté principale est l'animation d'ouverture : comme on ne peut pas animer de height: 0 à height: auto en CSS, j'ai utilisé la propriété max-height pour créer l'effet de glissement (transition).

Javascript

Un script simple écoute le clic sur le bouton burger pour ajouter/enlever la classe .open sur le header. J'ai aussi ajouté un écouteur sur les liens pour refermer le menu automatiquement après un clic, améliorant ainsi l'UX mobile.
