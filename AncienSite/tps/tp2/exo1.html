Analyse

Connaissances mises en jeu

Utilisation de la propriété grid-template-areas pour dissocier complètement l'ordre du code HTML (DOM) de l'ordre d'affichage visuel. J'ai défini une "carte" de ma grille en 3x3 et assigné chaque élément à sa zone nommée.

Intérêt de l'exercice

C'est fondamental pour le Responsive Design : cela permet par exemple de déplacer un menu ou un footer sur mobile sans devoir changer le code HTML, juste en redéfinissant les zones CSS.
