Analyse

Logique d'interaction

Pour répondre à la question 2, j'utilise un seul canvas. En JavaScript, je stocke l'index de la figure active dans une variable (currentFigureIndex). À chaque clic, j'efface complètement le canvas avec clearRect() avant de dessiner la figure suivante. Cela évite que les dessins ne se superposent.

Difficultés

La principale difficulté a été de rendre le code modulaire. Au lieu de tout écrire dans une seule fonction, j'ai créé une fonction distincte par figure (drawTarget, drawCheckerboard...) qui prend le ctx (contexte) en paramètre. Cela permet de garder le code propre et facile à maintenir pour le système de boucle.
