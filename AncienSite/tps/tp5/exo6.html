Étape 1 : Le Concept

L'effet parallaxe consiste à faire bouger l'arrière-plan à une vitesse différente du contenu. En CSS pur, l'astuce consiste à "figer" l'image de fond par rapport à la fenêtre du navigateur.

Comment ça marche ?

Normalement, quand vous scrollez, tout remonte. Avec le parallaxe CSS, l'image de fond reste scotchée en haut de la fenêtre (viewport), mais le bloc qui la contient (`div`) remonte et la masque progressivement. Cela crée une illusion de "fenêtre" sur l'image.

Étape 2 : La Propriété Magique

La seule ligne de CSS nécessaire pour obtenir cet effet est :

background-attachment: fixed;

Il faut l'appliquer sur un élément bloc qui possède une background-image.

Le code complet

Voici le snippet CSS typique utilisé sur cette page :

.parallax {
    background-image: url('image.jpg');
    height: 100vh; 
    background-attachment: fixed;
    background-size: cover;
}

Étape 3 : Attention au Mobile

Certains navigateurs mobiles désactivent cet effet pour économiser la batterie. L'image défilera alors simplement avec le reste de la page. C'est ce qu'on appelle la "dégradation gracieuse".

Analyse de l'exercice

Compétences mises en œuvre

Cet exercice m'a permis de comprendre la propriété background-attachment. J'ai appris à structurer une page en alternant des sections "héro" (visuelles) et des sections de contenu textuel pour rythmer la lecture.

Intérêt pour le Front-End

Le parallaxe est une technique essentielle du "Scrollytelling" (raconter une histoire via le scroll). C'est un effet visuel à fort impact mais très peu coûteux en performance puisqu'il n'utilise pas de JavaScript.
